LeetCode Companion

Pair this extension with your local dashboard. It only ever talks to this server.

What this extension does

  • On leetcode.com, it observes the page's own Submit / Run requests and their results to record your code, language and verdict.
  • On leetcode.com/studyplan pages, it can read the plan's question list from what the page loaded, and sends it to your dashboard only when you click Import in the side panel.
  • It estimates active time from tab visibility, window focus and recent input (no keystroke contents are read or stored).
  • It never sends requests to LeetCode itself and never stores your LeetCode credentials.
  • Data is sent only to the dashboard URL above (localhost), authenticated with the pairing token.
