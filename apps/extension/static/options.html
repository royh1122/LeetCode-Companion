LeetCode Companion

Pair this browser with your LeetCode Companion dashboard. It only ever talks to that dashboard.

On this computer: http://127.0.0.1:4317. In server mode: the address shown under Settings → Devices → Add a device.
You can paste the whole line from the dashboard into either field.

This address uses plain http. That is fine on a private network that encrypts traffic itself (Tailscale does), not on public Wi-Fi.

What this extension does

  • On leetcode.com, it observes the page's own Submit / Run requests and their results to record your code, language and verdict.
  • On leetcode.com/studyplan pages, it can read the plan's question list from what the page loaded, and sends it to your dashboard only when you click Import in the side panel.
  • It estimates active time from tab visibility, window focus and recent input (no keystroke contents are read or stored).
  • It never sends requests to LeetCode itself and never stores your LeetCode credentials.
  • Data is sent only to the dashboard address above, authenticated with this browser’s own key from pairing. Removing the device in the dashboard stops it.
