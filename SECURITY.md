# Security

LeetCode Companion runs only on your own computer. The dashboard listens on `127.0.0.1`, and the browser extension sends data only to that local dashboard, authenticated with a pairing token. There is no hosted service.

## Reporting a vulnerability

Please report security problems privately, through GitHub's **Report a vulnerability** button on this repository's **Security** tab, not in a public issue. Include the steps to reproduce and what an attacker could do.

Things that count as security problems here include: a web page or another site reaching the dashboard or its data, a page on leetcode.com making the extension do something it shouldn't, the pairing token leaking, or anything that could send your code or notes off your computer.

This is a personal project maintained in spare time, so there is no guaranteed response time.
